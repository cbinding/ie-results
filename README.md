# IE Results Viewer
Viewer for Information Extraction results on OASIS journal reports. Facilitates interactive adjustment of section and significance scores to affect results ranking.

[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/cbinding/ie-results/HEAD?urlpath=%2Fdoc%2Ftree%2Fie-results-viewer.ipynb)

To access the viewer, click the 'binder' link above. The initial build process may take a few minutes. Once built and opened
